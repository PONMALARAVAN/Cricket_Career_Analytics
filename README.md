📌 Project Overview:

This project turns raw cricket match data into a clear, interactive story of one of the game's greatest batters. The dashboard lets users filter by format and explore performance from multiple angles, from headline KPIs to detailed breakdowns by opponent, event and venue country.

🎯 Objectives:
Summarize career performance using key KPIs
Compare performance across formats, opponents, events and host countries
Track the growth of career runs over the years
Understand dismissal patterns and match result distribution

📊 Dashboard Features:
Section	Description
KPI Cards	Total Matches, Total Runs, Centuries, Average Strike Rate, Highest Score
Format Slicer	Filter all visuals by Select all / ODI / T20I / Test
Runs by Format	Bar chart comparing runs across ODI, Test and T20I
Career Runs by Progression	Line chart of cumulative runs by year
Match Result Distribution	Pie chart of Won, Lost, Drawn, NR and Tied
Runs against Opposition	Bar chart of runs scored versus each team
Dismissal Types	Donut chart of how he gets out (caught, bowled, lbw, run out, stumped, hit wicket)
Runs by Event	Bar chart across tournaments and series
Runs by Host Country	Map showing runs scored in each host country

🔍 Key Insights:
Career totals: 658 matches, about 28K runs, 85 centuries and a highest score of 254.
Best format: ODI contributes the most runs, followed by Test and then T20I.
Match results: Of the matches played, 382 (58.05%) were won, 222 were lost and 36 (5.47%) were drawn.
Dismissals: Caught is the most common dismissal type, at 380 dismissals (57.75%).
Opposition: Australia is the opponent against which he has scored the most runs.
Events: The Border-Gavaskar Trophy (about 2.2K) and the ODI World Cup (about 1.8K) are his highest run-scoring events.
